# Reel 1 — "Nobody Is Coming"

18-second, 1080×1920 loopable reel built with [HyperFrames](https://hyperframes.heygen.com).
Anton on black; white `#FFFFFF`, grey `#9A9A9A`, gold `#F5B700`. All text stays inside the safe area (250px top, 400px bottom).

**Rendered video:** [`nobody-is-coming.mp4`](nobody-is-coming.mp4)

| Sec | Text | Sound |
| --- | --- | --- |
| 0–2 | Nobody → is coming → to save you. (snaps, shake at 2) | bass hit, rumble, bass hit |
| 3–5 | No investor. / No mentor. / No perfect timing. (flash cuts) | ticks |
| 6 | black | silence |
| 7–8 | Just you. (grey, fade in, slow 10% zoom) | heartbeats |
| 9–10 | And that's the good news. (grey → gold, glow) | music enters and builds |
| 11–13 | Because it means / you don't need / permission. (slide up, gold) | riser |
| 14 | permission. alone, scales up | pause |
| 15–17 | white flash, Start (gold) / today. slams in, pulse | drop |
| 17.5–18 | hard cut to black, loops to 0 | cut |

Sound is synthesized by `assets/gen_nobody_audio.py` (`python3 assets/gen_nobody_audio.py out.wav`, needs numpy).
`npm run check` · `npm run dev` · `npm run render`
